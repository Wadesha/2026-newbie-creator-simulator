互动模拟器 · 设计说明（PRD）

1. 目标用户与场景

面向 2026 年想入行自媒体的纯素人。已有"全面架构报告 + 18 人画像库"做认知铺垫，本产品把抽象建议变成可操作的体验：用户扮演新人，每一步点击决策，直观感受"选择 → 数据反馈 → 走向分叉"。

2. 核心机制

  • 状态机：每个场景(scene)含叙事 + 2–4 个选项；选项带属性增减(eff)、设定(set)、分支标记(flag)与门槛(req)。
  • 六维属性：精力 / 预算 / 内容力 / 粉丝 / 累计收入 / 心态，实时面板常驻。
  • 真实数据锚点：首条内容曝光按平台基线 + 内容力 + 努力度 + 赛道匹配模拟，而非随机。
  • 分支剧情：首条数据高低 → 早期顺境/挣扎；是否坚持 → 不同变现路径；危机事件 → 不同结局。
  • 多结局：爆款出圈 / 稳定副业 / 佛系记录 / 安静生长 / 中途放弃 / burnout，由终局属性计算。

3. 交互与体验

纯原生 HTML/CSS/JS 单文件、零依赖、可离线；移动端属性面板改为 3 列、选项大点击区；含决策日志与一键重开，鼓励"多周目"对比不同打法。

4. 后续可扩展（已规划）

  • 把 18 人画像库直接接入开局身份，让数值起点更真实；
  • 加入"AI 复盘教练"在每个节点给建议；
  • 导出 30 天成长曲线图；
  • 增加"对标爆款""投流测试"等高级玩法节点。
