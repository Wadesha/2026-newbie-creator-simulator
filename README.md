# 2026 素人自媒体成长模拟器

一个面向「素人 / 新人自媒体创作者」的成长模拟器：通过互动玩法还原从 0 到 1 做自媒体的真实路径与决策后果。

## 在线体验

- GitHub Pages（推荐）：https://wadesha.github.io/2026-newbie-creator-simulator/
- 直接用浏览器打开根目录 `index.html` 亦可离线体验。

## 项目内容

| 文件 | 说明 |
| --- | --- |
| `index.html` | 主页面（GitHub Pages 入口） |
| `素人自媒体成长模拟器_v2.html` | 模拟器 v2 版本 |
| `素人自媒体成长模拟器_互动版.html` | 互动版模拟器 |
| `2026新人自媒体全面架构报告.md` | 自媒体全面架构报告 |
| `素人自媒体成长模拟器_扩充规划.md` | 扩充与迭代规划 |

## 本地运行

无需构建，克隆后直接用浏览器打开 `index.html` 即可：

```bash
git clone https://github.com/Wadesha/2026-newbie-creator-simulator.git
```
